# FS Frontend

Frontend do aplicativo desenvolvido com **Expo** e **React Native**.

## Instalação

Instale as dependências do projeto:

```bash
npm install
```

## Executar o projeto

Para iniciar o servidor de desenvolvimento:

```bash
npx expo start
```

Após iniciar, você poderá abrir o aplicativo utilizando:

- **Expo Go** no celular
- **Emulador Android**
- **Simulador iOS**
- **Navegador (Web)**
